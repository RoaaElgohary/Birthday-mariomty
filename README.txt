# Birthday.exe 💗

A responsive pink birthday website made with HTML, CSS and JavaScript.

## Quick setup
1. Open `script.js`.
2. Change `FRIEND_NAME`.
3. Change `SONG_NAME` and `SONG_LINK`.
4. Replace `MESSAGE` with your own message.
5. Put 4 photos inside `images/`:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   - photo4.jpg
6. Open `index.html` in a browser.

## Put it online
You can upload the folder to GitHub Pages, Netlify, or Vercel and send her the link.

Tip: For music, this version opens the selected song on YouTube/Spotify. Browsers often block websites from automatically playing music without a user click.
